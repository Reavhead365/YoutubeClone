# 📺 YouTube Clone (Frontend Layout)

A clean, responsive, pixel-perfect frontend replica of the YouTube home interface built using semantic HTML5 and custom CSS3 (Grid & Flexbox).

---

## 🌟 Key Features

* **Authentic YouTube Header:** Navigation bar featuring a search input, icon buttons, and a clean circular letter profile badge ("H").
* **Responsive Multi-Column Grid:** Built using CSS Grid `repeat(auto-fill, minmax(300px, 1fr))` for fluid responsive rendering across desktop and mobile screens.
* **Component-Based CSS Structure:** Clean separation of concerns with dedicated stylesheets (`general.css`, `header.css`, and `video.css`).
* **Vector Graphics:** Embedded SVGs for sharp, high-DPI header action buttons.
